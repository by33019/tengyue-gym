## 二、AI Coze Agent 模块

**问：现在进行下一个迭代的开发，我的 coze 那个 agent 服务已经启用**

答：设计了完整方案——6 个 API 端点（5 个 SSE 流式 + 1 个额度查询），Spring SseEmitter 管理前后端连接，RestTemplate 调用 Coze API。前端 AiPage.vue 改为功能卡片 + 对话流 + 打字机效果。

---

**问：每个模块的回答都是固定的，无法随机实时返回**

答：排查发现请求体格式完全不匹配。Coze 工作流 API 的正确格式是：
```json
{
  "content": {"query": {"prompt": [{"type": "text", "content": {"text": "..."}}]}},
  "type": "query",
  "session_id": "...",
  "project_id": "7640283069890609190"
}
```
参考 `doc/gym_coze.py` 后修正了请求体结构。

---

**问：还是不行，每个节点回复都是固定一直不变的**

答：深入排查发现 401 Unauthorized。`mvn spring-boot:run` 不自动加载 `.env` 文件，`COZE_API_TOKEN` 环境变量为空。Spring Boot 读到的是空字符串，实际发送 `Authorization: Bearer `（空 token）。Python 脚本能跑通是因为 token 硬编码在代码里。解决方案：启动时显式传入环境变量。

---

**问：现在还是无法调用到我的 coze 功能**

答：用 `HttpURLConnection` 替换了 `RestTemplate.execute()`，确保请求头正确设置。同时修复 `project_id` 格式（字符串 vs 数字）。

---

**问：现在已经可以了，但是需要将 AI 回答改成流式输出**

答：前端 SSE 解析字段不对——代码取 `json.message`，实际 Coze 返回 `json.content.answer`。修复后逐 chunk 追加并加 15ms 延迟，实现打字机逐字效果。

## 四、角色权限重构

**问：教练和管理员不应该有健身打卡、训练计划等功能，而是对用户端进行管理**

答：重新设计了三种角色：

| 角色 | 导航 |
|:---|:---|
| 学员 | 首页/打卡/计划/统计/排行/社区/AI/我的 |
| 教练 | 工作台/打卡/计划(发模板)/AI/我的 |
| 管理员 | 管理台/个人中心 |

改造 12 个文件：路由守卫按角色拦截、侧边栏/底部导航三套菜单、登录后角色分流跳转、后端全部管理端点加权限校验。

---

**问：教练端还可增加一个发布训练计划的功能，还可以加个健身打卡和学员管理**

答：调整方案：教练端保留打卡 + 训练计划（含模板发布），新增学员管理。`user` 表加 `coach_id` 字段建立学员→教练关系。教练可从未分配列表收学员、移除学员、发提醒。

---

**问：教练端的移除学员功能还是无法实现**

答：MyBatis-Plus 默认策略 `NOT_NULL` 导致 `setCoachId(null)` 被跳过，SQL 不更新该列。改用 `LambdaUpdateWrapper.set(User::getCoachId, null)` 显式指定 SET NULL，问题解决。

---

**问：将管理员端的提醒记录删除，管理员不需要这个功能；教练端的提醒和移除功能还不能使用**

答：管理员 tabs 去掉提醒记录。所有管理操作按钮加了 try/catch + alert 错误提示，便于定位问题。PUT 请求统一加上空 body `{}`。

---

**问：管理员端修改：内容审核放到侧边栏、教练不显示"无教练"、注册时可选角色**

答：
1. 管理员侧边栏新增"内容审核"入口，通过 query 参数 `/admin?tab=posts` 直达
2. 管理员用户列表只对学员显示教练信息
3. 注册表单增加"普通用户"/"教练"选择器，注册成功后自动登录跳转

---

**问：注册的是教练，进去却不是教练的工作界面；管理员端无法删除用户**

答：后端一直跑旧代码未重启。`AuthServiceImpl.register()` 此前硬编码 `user.setRole(0)`，前端选"教练"也被覆盖为普通用户。重启后端 + 新增 `DELETE /api/admin/user/{id}` 删除用户端点后问题解决。

## 关键踩坑经验

1. **Spring Boot 不自动加载 `.env`**——本地 `mvn spring-boot:run` 需显式设置环境变量，Docker Compose 才会自动读取
2. **MyBatis-Plus 默认不更新 null 值**——需用 `LambdaUpdateWrapper` 显式 `.set()` 才能将字段设为 null
3. **Coze Workflow API ≠ Chat API**——请求体格式完全不同，需以实际 SDK 代码（Python 脚本）为准
4. **SSE 流式前端渲染**——需加 `setTimeout` 延迟逐字显示才有打字机效果
5. **角色重构要同步多端**——路由守卫、侧边栏、底部导航、后端 API 校验缺一不可
6. **RestTemplate 回调方式不可靠**——改用原生 `HttpURLConnection` 确保请求头正确应用
