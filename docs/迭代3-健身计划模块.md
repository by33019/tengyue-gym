# 迭代3：健身计划模块

## 后端任务

| 接口 | 方法 | 路径 | 说明 |
|:---|:---|:---|:---|
| 创建计划 | POST | `/api/plan` | 含计划明细（每日动作安排） |
| 计划列表 | GET | `/api/plan/list` | 我的计划列表，按状态筛选 |
| 计划详情 | GET | `/api/plan/{id}` | 计划信息 + 明细列表 |
| 编辑计划 | PUT | `/api/plan/{id}` | 修改计划及明细 |
| 启用/停用 | PUT | `/api/plan/{id}/status` | 状态切换 |
| 模板列表 | GET | `/api/plan/templates` | 公共计划模板（督导/管理员发布） |

## 业务规则
- 计划来源：手动 / AI / 模板
- 难度：入门 / 进阶 / 高级
- 计划连续 3 天未执行，返回提示（在前端展示）
- 计划执行率连续低于 50%，提示降低难度

## 数据表
- `plan` — 健身计划表
- `plan_detail` — 计划明细表

## 后端涉及文件
- `entity/Plan.java` + `entity/PlanDetail.java`
- `mapper/PlanMapper.java` + `mapper/PlanDetailMapper.java`
- `dto/PlanDTO.java` — 计划请求 DTO（含明细列表）
- `dto/PlanQuery.java` — 分页查询 DTO
- `service/PlanService.java` + `service/impl/PlanServiceImpl.java`
- `controller/PlanController.java`

## 前端任务
- 计划列表页 — 当前计划卡片 + 状态标签 + 新建入口
- 计划创建页 — 手动/模板切换，明细编辑（星期+动作+组数+次数）
- 计划详情页 — 日历视图展示每日安排
- Axios API 模块（`api/plan.ts`）

## 页面清单
- `/plan` — 我的计划
- `/plan/create` — 创建计划
- `/plan/:id` — 计划详情

## 测试类型
- 后端单元测试 + 接口测试（计划 CRUD、模板、状态切换）
