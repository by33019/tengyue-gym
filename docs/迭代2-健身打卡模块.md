# 迭代2：健身打卡模块

## 后端任务

| 接口 | 方法 | 路径 | 说明 |
|:---|:---|:---|:---|
| 创建打卡 | POST | `/api/checkin` | 运动类型/时长/消耗/配图/备注，校验每日上限 3 次 |
| 打卡列表 | GET | `/api/checkin/list` | 分页查询，按时间倒序 |
| 打卡日历 | GET | `/api/checkin/calendar` | 月视图数据，返回每日打卡次数 |
| 今日次数 | GET | `/api/checkin/today-count` | 返回今日已打卡次数 |
| 导出记录 | GET | `/api/checkin/export` | 导出 Excel/CSV |

## 业务规则
- 每日打卡上限 3 次（写入前校验）
- 打卡图片自动添加时间戳水印
- 连续打卡天数统计（查询时实时计算）

## 数据表
- `check_in` — 打卡记录表

## 后端涉及文件
- `entity/CheckIn.java`
- `mapper/CheckInMapper.java`
- `dto/CheckInDTO.java` — 打卡请求 DTO
- `dto/CheckInQuery.java` — 分页查询 DTO
- `service/CheckInService.java` + `service/impl/CheckInServiceImpl.java`
- `controller/CheckInController.java`
- `util/ImageWatermark.java` — 图片水印工具

## 前端任务
- 打卡页面 — 运动类型选择 + 时长/消耗输入 + 图片上传 + 备注
- 打卡日历页面 — 月历热力图展示
- Axios API 模块（`api/checkin.ts`）

## 页面清单
- `/checkin` — 打卡
- `/checkin/calendar` — 打卡日历

## 测试类型
- 后端单元测试 + 接口测试（每日上限校验、分页、导出）
