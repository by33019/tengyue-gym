# 迭代1：用户认证与个人中心

## 后端任务

| 接口 | 方法 | 路径 | 说明 |
|:---|:---|:---|:---|
| 注册 | POST | `/api/auth/register` | 用户名+密码+运动基础评估，BCrypt 加密 |
| 登录 | POST | `/api/auth/login` | 返回 Access Token + Refresh Token |
| 刷新 | POST | `/api/auth/refresh` | Refresh Token 换取新 Access Token |
| 个人信息 | GET | `/api/user/profile` | 获取当前用户详情 |
| 更新信息 | PUT | `/api/user/profile` | 修改身高/体重/健身目标/运动等级 |
| 修改密码 | PUT | `/api/user/password` | 旧密码验证 + 新密码 |
| 上传头像 | POST | `/api/user/avatar` | 图片上传 ≤5MB，返回 URL |
| 注销账号 | PUT | `/api/user/deactivate` | 软删除，30 天恢复期 |

## 数据表
- `user` — 用户表（含身体数据、运动等级、状态）

## 后端涉及文件
- `entity/User.java` — 用户实体
- `mapper/UserMapper.java` — MyBatis-Plus Mapper
- `dto/RegisterDTO.java` — 注册请求 DTO（含运动评估问卷）
- `dto/LoginDTO.java` — 登录请求 DTO
- `dto/ProfileDTO.java` — 个人信息更新 DTO
- `dto/PasswordDTO.java` — 密码修改 DTO
- `service/UserService.java` + `service/impl/UserServiceImpl.java`
- `controller/AuthController.java`
- `controller/UserController.java`

## 前端任务
- 登录/注册页面（Tab 切换）— 注册时含运动基础评估问卷
- 个人中心页面 — 信息展示 + 编辑表单 + 头像上传
- Axios API 模块（`api/auth.ts` + `api/user.ts`）

## 页面清单
- `/login` — 登录/注册
- `/profile` — 个人中心

## 测试类型
- 后端单元测试 + 接口测试（200/400/401/403 全覆盖）
