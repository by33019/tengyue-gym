# 迭代4：数据统计与社区

## 后端任务

### 数据统计

| 接口 | 方法 | 路径 | 说明 |
|:---|:---|:---|:---|
| 数据总览 | GET | `/api/stats/summary` | 运动总时长/总消耗/打卡天数/平均时长/环比 |
| 趋势数据 | GET | `/api/stats/trend` | 周/月趋势（支持 period 参数） |
| 排行榜 | GET | `/api/stats/ranking` | 周/月打卡天数榜 + 消耗榜（Top20，支持匿名） |

### 社区模块

| 接口 | 方法 | 路径 | 说明 |
|:---|:---|:---|:---|
| 发布动态 | POST | `/api/post` | 文字+图片（最多 9 张） |
| 动态列表 | GET | `/api/post/list` | 分页 Feed 流，按时间倒序 |
| 删除动态 | DELETE | `/api/post/{id}` | 软删除（本人或管理员） |
| 点赞/取消 | POST | `/api/post/{id}/like` | 切换点赞状态 |
| 发表评论 | POST | `/api/comment` | 支持 parent_id 二级评论 |
| 评论列表 | GET | `/api/comment/list` | 按帖子 ID 查询，树形结构 |

## 业务规则
- 排行榜每日凌晨定时更新（Redis 缓存）
- 健身数据仅本人与督导可见
- 评论不可编辑，仅可删除
- 举报功能（记录举报信息，管理员审核）

## 数据表
- `post` — 社区动态表
- `comment` — 评论表（二级评论）

## 后端涉及文件
- `entity/Post.java` + `entity/Comment.java`
- `mapper/PostMapper.java` + `mapper/CommentMapper.java`
- `dto/PostDTO.java` + `dto/CommentDTO.java`
- `service/StatsService.java` + `service/PostService.java` + `service/CommentService.java`
- `controller/StatsController.java` + `controller/PostController.java` + `controller/CommentController.java`

## 前端任务
- 数据统计页 — ECharts 折线图/饼图/热力图
- 排行榜页 — 周/月切换 Tab，Top20 列表，匿名开关
- 社区页 — Feed 流 + 点赞/评论 + 发布动态弹窗
- Axios API 模块（`api/stats.ts` + `api/post.ts` + `api/comment.ts`）

## 页面清单
- `/stats` — 数据统计
- `/ranking` — 排行榜
- `/community` — 社区

## 测试类型
- 后端单元测试 + 接口测试 + 前端组件测试（图表渲染、Feed 流、评论树）
